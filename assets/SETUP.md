# SudiptoKumar profile setup

This package mirrors the reference profile architecture: theme-aware animated banner, self-updating stats/languages, animated contribution snake, and animated project cards.

## 1. Update your existing profile repository

Do not create another repository. Use your existing `SudiptoKumar/SudiptoKumar` repository.

Replace/upload these files and folders:

- `README.md`
- `assets/dark.svg`
- `assets/light.svg`
- `assets/projects.json`
- `.github/`
- `gen_banner.py`
- `portrait_dark_runs.json`
- `portrait_light_runs.json`

Keep `step1_mask.py` and `step2_dither.py` if you still use them.

## 2. GitHub Actions permission

Repository → Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save.

## 3. Run the two workflows

Run:

1. `Generate Snake Animation`
2. `Generate Projects, Stats and Languages`

The first creates the `output` branch with the animated snake.

The second creates the `projects` branch containing:

- `projects.svg`
- `projects-assets/light.svg`
- `stats.svg`
- `stats-assets/light.svg`
- `languages.svg`
- `languages-assets/light.svg`

## 4. No Vercel setup is required

Stats and languages are generated by your own GitHub Actions workflow and loaded from your `projects` branch.

## 5. All public projects

`assets/projects.json` enables automatic discovery. The workflow includes all owned public, non-fork, non-archived repositories except the profile repository itself. Each repository receives a deterministic logo automatically.

## 6. Future updates

The project workflow runs every 6 hours. The snake workflow runs every 12 hours. You can also run either workflow manually from the Actions tab.
